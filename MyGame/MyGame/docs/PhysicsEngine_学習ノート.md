(1) Update
・まずは全員を動かしてみて、その結果めり込んでしまった奴らを後から押し戻している。

(2) Integrate
・MyVector3 vel = obj->GetVelocity();
　MyVector3 pos = obj->transform.GetPosition();で現在の速度と座標を取得
・vel.y += GRAVITY * dt;重力を適用する。
・重力とdtを掛け合わせたものを足すことで徐々にに落下速度が速　くなる重力落下を再現。
・pos.x += vel.x * dt;
　pos.y += vel.y * dt;
　pos.z += vel.z * dt;速さと時間で位置を出す。
・obj->SetVelocity(vel);
　obj->transform.SetPosition(pos.x, pos.y, pos.z);
　obj->transform.UpdateMatrix();
　計算で新しくなった速度と座標を適用する。
※ DeltaTimeを引数にしdtを掛けるとどんな性能のPCでも「1秒間に進む距離」を同じに統一している。

(3) 判定ペアの作成 (ResolveCollisions)
■ Dynamic vs Static (動くモノ vs 動かないモノ)
・for文(二重ループ)を使って、考えられるすべての組み合わせを総当たりでチェックしている。
■ Static vs Static (動かないモノ同士)
・壁や床など「動かない物同士」の当たり判定をチェックしてもゲームに影響を与えない。
・ただ処理が重くなるだけの完全な「無駄な計算」になるため、意図的にこのペアは作らない仕様になっている。
■ Dynamic vs Dynamic (動くモノ同士) 
・for文を使って総当たりでチェックしているが、内側のループ(j)を「i + 1」から始める工夫をしている。
・これにより以下の2つを完全に防止し、計算量をピッタリ半分に減らしている。
  ① 自分自身と当たっているか調べる無駄（自己判定の防止）
  ② AvsBの後に、BvsAを調べてしまう無駄（重複判定の防止）

(4) CheckAndResolveCollision
・オブジェクトをポインタで参照し、コライダーの配列を読み込み「Aの全コライダー × Bの全コライダー」の総当たりチェックを行っている。
※ for (const auto& col : ...) と参照渡し(&)にすることで、重いコライダーデータの「無駄なコピー」を防いで処理を高速化しつつ、データだけを安全に読み込んでチェックしている。
・判定を行う前にGetWorldを呼び出し親の位置と大きさを考慮した上で当たり判定チェックをしている。
・isTriggerがtrueなら押し返す処理は呼ばず、OnTriggerEnter のみ呼ぶ。
・isTriggerがfalseなら押し返す処理を呼び出し、OnCollisionEnter を呼ぶ。

(5) Resolve...Overlap系
■ AABB同士
・x, y, z の各軸において、「重なっている部分の右端(min(max,max))」から「左端(max(min,min))」を引くことで、それぞれのめり込み量を求める。
・xyzで一番めり込みが小さい面を探し、お互いの位置関係から「押し出す向き（プラスかマイナスか）」を決定する。
・その面の「法線(押し出す方向)」と「めり込み量」を ApplyImpulse に渡し、押し返す処理を任せる。
■ Sphere VS AABB
・Clampを使って球の中心座標をAABBの範囲内に押し込み、AABB表面における「一番球に近い点（最近接点）」を割り出す。
・球の中心座標から最近接点の座標を引き算(dx, dy, dz)することで、2点間を繋ぐベクトル（矢印）を作成する。
・そのベクトルを使って球の中心から最近接点までの距離(dist)を算出し、「球の半径 － 距離」でめり込み量を求める。
  ※距離がほぼ0の場合は、その後の計算(ゼロ除算)でクラッシュするのを防ぐため処理を中断する安全装置を入れている。
・先ほど作ったベクトル(dx, dy, dz)は向きだけでなく距離も持っているので、距離で割って正規化し、法線（押し出す方向）とする。
・引数(isSphereMove)によって「球側と箱側どちらを押し戻すか」を判断して向きを調整し、ApplyImpulseに渡し押し返す。
■ Capsule vs AABB
・カプセルの芯（線分）の中からAABBに最も近い1点を見つけ出し、そこを「カプセルと同じ半径の仮想の球」とみなす。
・これにより、基本的には直前の「Sphere vs AABB」と全く同じ計算でめり込み量と法線（押し出す方向）を求めることができる。
・【プロの安全装置（フェイルセーフ）】
  もし高速移動などで「カプセルの芯自体がAABBの完全に内部に埋まってしまった」場合（距離がほぼ0の時）、上記の計算が破綻してしまう。
  そのため、緊急措置として「AABBの6つの面（前後左右上下）までの距離をすべて測り、一番近い壁に向かって強制的に引っこ抜く（距離＋半径分を押し戻す）」という処理をelseブロックで行い、壁埋まりバグを防止している。
